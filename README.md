# WorldSkills Graphic Design 2027 — учебный ресурс

Открытый русскоязычный курс для 2–3 студентов колледжа Hexlet, которые готовятся к компетенции Graphic Design Technology. Он дополняет занятия преподавателя: помогает повторить тему, пройти короткую практику и проверить готовый файл.

> **План предварительный.** Первый маршрут рассчитан на 20 октября 2026 — 31 января 2027 и построен по доступным материалам 2026 года. Он не предсказывает задание, дату или правила WorldSkills Almaty 2027. После публикации официальных условий преподаватель сверит каждое изменение и перестроит практику. Стандарт WorldSkills 2026 — международный ориентир, а не местный регламент.

## Учебный маршрут

Начните с [главной страницы](index.html), затем проходите модули по порядку. Сейчас программа состоит из девяти модулей: бриф и процесс, InDesign, Illustrator, Photoshop, печать, цифровой дизайн, качество сдачи, конкурсный английский и испытания. Для самостоятельного занятия используйте бриф урока, критерии и объяснение в квизе; для печати есть [календарь](timeline.html) и [версия для печати](print.html).

Ориентировочная нагрузка: 228 часов до 31 января — 168 часов занятий и практики с преподавателем и 60 часов самостоятельной работы. Месячное распределение — в календаре. После объявления условий начинается событийный этап адаптации; для него календарная дата заранее не задаётся.

## Публикация и общение

Сайт рассчитан на GitHub Pages, а вопросы и добровольный разбор учебных работ — на [GitHub Discussions](community.html). Репозиторий и обсуждения публичны. Работы публиковать не обязательно; не указывайте ФИО, контакты или другие личные данные и не загружайте материалы чемпионата, если правила запрещают их распространение.

## Актуальность материалов

В [каталоге источников](sources.html) указаны издатель, версия, область применения, статус и дата последней проверки. Материалы Казахстана 2026 служат временной локальной основой. Примеры модулей из WS_KZ_GDT_2026 обозначены как учебные проекты, а не официальное конкурсное задание. Документы, копии которых не нужны для обучения, в репозиторий не включены. Старые версии общих документов WorldSkills отмечены как заменённые.

Редактору: перед каждым месяцем проходите [чек-лист актуальности](docs/source-update-checklist.md) и сверяйте установленные приложения по [аудиту версий](docs/software-version-audit.md). Для улучшения уроков используйте [лист наблюдения пилотного занятия](docs/pilot-observation-sheet.md). При первой официальной публикации Almaty 2027 проведите сверку отличий и запишите новые источники до изменения уроков.

## Локальный запуск и редактирование

Откройте `index.html` локальным статическим сервером или включите GitHub Pages в Settings → Pages → Deploy from a branch → `main` / root. GitHub Pages публикует статические файлы без сборки. Для проверки структуры и свежести данных нужен Node.js 20 или новее:

```text
node --test
node scripts/validate-course.mjs --strict-current
```

Уроки и каталоги хранятся в JSON, страницы — в HTML, стили — в `assets/css/site.css`. Перед публикацией проверьте ссылки, даты и экранные ширины из checklist.

## Лицензирование и права

Курс и оригинальные схемы можно использовать и адаптировать с указанием источника, если для файла не указан иной автор/лицензия. Товарные знаки Adobe и WorldSkills принадлежат правообладателям; они упоминаются только для описания учебных тем. Оригинальные задания не копируют конкурсные проекты. Проверьте статус лицензии внешних ресурсов перед повторным использованием их изображений или текстов.
